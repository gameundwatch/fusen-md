## 目指す挙動

- **フォーカスあり（アクティブ）** → 編集モード（`<textarea>`）
- **フォーカス喪失（非アクティブ）** → プレビューモード（`ReactMarkdown`）
- **ウィンドウが非アクティブでも** マウスホバー中にホイールすればそのプレビューだけがスクロール

ブラウザ／Electron のイベントだけで完結します。外部ライブラリ追加不要、既存 Flex レイアウトも変更不要です。

---

### 1. フォーカス状態を React で検知する

```tsx
// src/renderer/hooks/useWindowFocus.ts
import { useEffect, useState } from 'react';

export function useWindowFocus() {
  const [focused, setFocused] = useState<boolean>(document.hasFocus());

  useEffect(() => {
    const onFocus = () => setFocused(true);
    const onBlur  = () => setFocused(false);

    window.addEventListener('focus', onFocus);
    window.addEventListener('blur',  onBlur);
    return () => {
      window.removeEventListener('focus', onFocus);
      window.removeEventListener('blur',  onBlur);
    };
  }, []);

  return focused;
}
```

### 2.  NoteWindow でモードを切り替える

```tsx
// src/renderer/components/NoteEditor.tsx
import { useState, useRef } from 'react';
import ReactMarkdown from 'react-markdown';
import remarkGfm    from 'remark-gfm';
import remarkBreaks from 'remark-breaks';
import { useWindowFocus } from '../hooks/useWindowFocus';

export default function NoteEditor() {
  const isFocused   = useWindowFocus();          // ← ①
  const [text, setText] = useState('');
  const previewRef  = useRef<HTMLDivElement>(null);

  return (
    <div className="note-window">
      {/* header / toolbar はそのまま */}

      <main className="note-main">
        {isFocused ? (
          /* ② アクティブ時: 編集 */
          <textarea
            className="note-textarea"
            value={text}
            onChange={(e) => setText(e.target.value)}
          />
        ) : (
          /* ③ 非アクティブ時: プレビュー */
          <div
            ref={previewRef}
            className="note-preview"
            /* ホイール伝搬は OS 依存。以下は念のための保険 */
            onWheel={(e) => {
              // このウィンドウにフォーカスを奪わせない
              if (!isFocused) e.preventDefault();
              previewRef.current!.scrollTop += e.deltaY;
            }}
          >
            <ReactMarkdown
              children={text.replace(/\r\n/g, '\n')}
              remarkPlugins={[remarkGfm, remarkBreaks]}
            />
          </div>
        )}
      </main>
    </div>
  );
}
```

* **ポイント**

  * `window.focus` / `blur` は **OS ウィンドウのフォーカス** をそのまま拾える。
  * 状態を一つ持つだけなので Redux／Jotai へ波及させる必要なし。

### 3.  ホバー中スクロールの OS 依存について

* **macOS / 主要 Linux デスクトップ** → 標準で「非アクティブウィンドウのホイールスクロール」をサポート。上記コードだけで動きます。
* **Windows 10+** → 既定で有効ですが、もし動かなければ

  * 設定 → Bluetooth とデバイス → マウス → **「ポインターを合わせた非アクティブ ウィンドウをスクロールする」** を ON にする
  * レジストリなら `HKCU\Control Panel\Desktop` → `MouseWheelRouting=2`

アプリ側でこれを強制する API は無いため、**OS 側フラグをオフにされている場合はユーザー設定が必須**です。

### 4.  小さな改善アイデア

| 目的                  | 1 行で出来ること                                                 |
| ------------------- | --------------------------------------------------------- |
| フォーカスを奪わずクリックで選択コピー | `<div onMouseDown={(e)=>e.preventDefault()}>` でテキスト選択のみ許可 |
| クリックした瞬間だけ編集に戻したい   | `onClick={() => window.focus()}` をプレビュー最外層に               |
| プレビュー ↔ 編集をアニメ付きで切替 | `framer-motion` の `<AnimatePresence>` をラップする              |
